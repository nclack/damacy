Reading the measurements

Image throughput
Requested image bytes delivered per second, counted in the source data type. Converting uint16 to float32 does not increase this number.
Compression ratio
Uncompressed image bytes in the stored arrays divided by their file bytes. Larger values mean less storage is needed.
Storage bandwidth
Read bytes per second recorded by Linux for the storage system. This includes any extra reads needed to deliver the requested pixels.
IOPS
Completed read operations per second recorded by Linux for that same storage system. One file read request can produce several storage operations.

Image throughput and storage bandwidth use GiB/s, where 1 GiB is 2³⁰ bytes. IOPS uses reads/s. All rates use elapsed measurement time, including reading, decoding, and final GPU completion. Initialization, warmup, and cache clearing are excluded. The Storage system section identifies the shared hardware; Diagnostics contains reader-level counters.

Measurement limits

The observed frontier compares settings within the same input, read pattern, backend, machine session, and storage condition. Filters recompute it. Connections join measured points; they do not predict unmeasured settings. All compared panels use the same axes.

Ranges are observed minima and maxima, not confidence intervals. Use the measurements table or keyboard to select overlapping points. Pilot studies cover a limited set of settings and do not establish a final frontier.

Compression ratio includes padding, shard indexes, and array metadata. Mixed studies use expanded, tiled source distributions. A ratio below one means the files are larger than the uncompressed image bytes. The compression axis is logarithmic.

Cold studies verify zero resident data-file pages before each timed pass; codecs and metadata are warmed. Earlier cached studies replay files preloaded into RAM. Storage counters include read-ahead and other activity on the same drives. Idle measurements are available in Diagnostics, and SSD/controller caches are not controlled.
